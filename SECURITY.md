# CrossCert Security Policy

CrossCert is designed with user safety and transparency in mind. We follow best practices for secure automation and config handling.

## 🔐 Key Principles

- No secrets stored in source code
- Config backups before modification
- Retry logic to prevent service overload
- Port detection (planned in v2) to reduce exposure

## 🧭 Reporting Vulnerabilities

If you discover a security issue, please open a private GitHub issue or email the maintainer directly. Do not disclose vulnerabilities publicly until resolved.
