# Contributing to CrossCert

Thank you for your interest in contributing to CrossCert! This project is built on principles of transparency, stewardship, and theological integrity. We welcome thoughtful contributions that align with these values.

## 🧭 Getting Started

- Fork the repository
- Clone your fork: `git clone https://github.com/your-username/CrossCert.git`
- Create a branch: `git checkout -b feature/your-feature-name`
- Commit using [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/)
- Push and open a pull request to `dev`

## 🧾 Commit Message Format


Examples:
- `feat(gui): add domain status panel`
- `fix(cert): retry logic for renewal failures`

## 🧪 Code Style & Structure

- Keep modules clean and focused
- Use dependency injection where appropriate
- Avoid hardcoded paths or secrets
- Respect config overrides and user autonomy

## 🛡️ Integrity Guidelines

- Do not introduce theological bias or distortion
- Avoid speculative or misleading automation
- Ensure all user-facing messages are clear and respectful

## 🤝 Collaboration

- Be kind and constructive in code reviews
- Ask questions if unsure — we’re here to help
- Use GitHub Issues to propose features or report bugs
