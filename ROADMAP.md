# ✝️ CrossCert

CrossCert is a free, open-source certificate automation tool designed for clarity, autonomy, and theological integrity. It helps users manage HTTPS certificates with confidence, transparency, and peace of mind.

## 🌟 Features

- ✅ Automated certificate issuance and renewal
- 🔁 Background service with retry logic and logging
- 🛡️ Configurable backup system for HTTP configs
- 📊 GUI dashboard (planned) with live domain status
- 🔒 Port advisory system (planned for v2)
- 🔔 GitHub release check and update notifications

## 🧭 Philosophy

CrossCert is built on principles of stewardship, accessibility, and spiritual clarity. It honors user autonomy by allowing manual config editing, transparent logging, and respectful error handling. All features are designed to serve users without intrusion or bias.
